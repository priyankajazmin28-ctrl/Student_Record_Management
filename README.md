# Student Record Management System

## About
A Python-based Student Record Management System.

## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- JSON File Storage
- Exception Handling

## Concepts Used
- Python Functions
- Parameters and Return Values
- Lambda Functions
- List Comprehension
- JSON File Handling
- Try-Except Handling

## How to Run
1. Install Python.
2. Open the project folder.
3. Run: py main.py
